# 쇼핑몰 장바구니 & 할인 쿠폰

## 실행 방법

```bash
python shop.py
```

프로그램 실행 후 메뉴 번호를 입력하여 쇼핑몰 기능을 이용할 수 있습니다.

## 구현 기능

- 상품 번호 자동 생성 및 상품 목록 조회
- 상품 재고 및 품절 상태 확인
- 장바구니 상품 추가 및 수량별 제거
- 할인 쿠폰 선택 및 적용
  - 10% 할인 (최대 5,000원)
  - 3,000원 할인 (20,000원 이상 구매 시)
- 할인 후 금액에 따른 배송비 계산
- 결제 영수증 출력 및 재고 감소
- 결제 후 장바구니 및 쿠폰 초기화

## 학습 내용

- 클래스와 객체
- 클래스 변수와 인스턴스 변수
- 상속 및 메서드 오버라이딩
- 다형성과 객체 조합
- 캡슐화
- 딕셔너리 및 반복문 활용
